# Backend

Minimal backend scaffold for the chef booking project.

## Layout

- `app/main.py`: application entry point
- `app/api/routes/`: route modules
- `app/models/`: database models
- `app/schemas/`: request and response schemas

## Next steps

2. Set up configuration and environment variables.
3. Add database models for chefs, customers, and requests.
